# Screenshot Evidence Directory

Store all verification screenshots in this folder as supporting evidence for the deployment and validation process.

### Required Screenshot Files

| Screenshot File            | Description                                                                                                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **local_docker_build.png** | Capture showing the successful completion of the Docker image build process on the local machine.                                                                                |
| **azure_acr_portal.png**   | Azure Portal view displaying the Azure Container Registry (`learnacrolamc`), including the repository and the published image tag (`v4.0`).                                      |
| **azure_aci_portal.png**   | Azure Portal screenshot showing the deployed Container Instance (`flask-acr-demo`) in a **Running** state, together with its assigned public Fully Qualified Domain Name (FQDN). |
| **web_app_live.png**       | Browser screenshot confirming that the deployed web application is accessible and functioning correctly through its public endpoint.                                             |

### Purpose of the Screenshots

These images provide visual confirmation of each stage of the deployment lifecycle, including image creation, registry publication, container execution, and application accessibility. The screenshots serve as evidence that the solution was successfully deployed and validated within the Azure cloud environment.
